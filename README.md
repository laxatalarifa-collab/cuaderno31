# Oviedo 2031 · Cuaderno de la visita

HTML preparado para GitHub Pages. Incluye Espacios, Recorrido, Contactos, Boceto y Timeline, con fotografías externas y atribuciones. No incluye la valoración.

## Publicar

1. Crear un repositorio llamado `oviedo-2031-visita`.
2. Subir `index.html`, `.nojekyll` y este README a la rama `main`.
3. En Settings → Pages, elegir Deploy from a branch, rama `main`, carpeta `/ (root)` y guardar.
4. GitHub mostrará el enlace publicado una vez terminado el despliegue.

Las fotografías necesitan conexión a internet. El enlace de GitHub Pages permite navegar por el HTML; los documentos de Drive conservan sus propios permisos.
